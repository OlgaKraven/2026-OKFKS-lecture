# Учебная инфографика ОКФКС

Основа интеграции — опубликованный коммит [`e4cfe69a4a5286bb9a7da58a7fda507436af9218`](https://github.com/OlgaKraven/2026-OKFKS-lecture/commit/e4cfe69a4a5286bb9a7da58a7fda507436af9218), GitHub Pages run `39777679411`. Исходники и публичные файлы сверены с артефактом публикации. MD с текстами лекций и сценариями хранятся только в BrainM; архивы остаются в репозитории; удалённые публичные ресурсы не возвращаются.

Курс: 7 лекций, 777 исходных слайдов. Инфографика применяется по учебной задаче: 116 структурных разборов схем и таблиц, 12 подробных представлений исходных данных и 13 добавлений к примерам. Всего 141 слайд с визуальным разбором; подробные 25 спецификаций содержат 55 сценариев и 297 кадров.

## Исходники

- `src/infographics/data/semester7.json` — лекции 1–4.
- `src/infographics/data/semester8.json` — лекции 5–7.
- `Diagrams.tsx` — геометрия, формальные формы, таблицы, числовые шкалы.
- `playback.ts` — полные снимки, шаги, пауза, ветвления и время.
- `LearningVisual.tsx` — доступные органы управления, раскрытие, синхронизация преподавателя и аудитории, печатное приложение.
- `learning-visuals.css` — светлая/тёмная тема и адаптация размеров.
- `vendor/lecture-engine-visuals/` — исходные изменения и происхождение локального runtime движка.

Содержание `public/course.json`, slideId, задания, ключи и тексты преподавателя этой доработкой не изменяются. Новая схема может менять способ показа прежнего visual; его исходные данные остаются в курсе.

## Управление и смысл анимации

Шаг 0 показывает обзор. Загрузка, прокрутка и раскрытие не запускают проигрывание. «Далее» и «Назад» восстанавливают полный кадр. «Показать» запускает выбранный конечный сценарий; «Пауза» сохраняет и положение маркера, и остаток остановки на событии. Возобновление не перескакивает через кадр. На последнем кадре доступно повторение выбранного сценария.

Смена условия останавливает движение и возвращает к последнему доказанному общему кадру, не перематывая вперёд. Каждый frame содержит полный focus, edges, caption и при необходимости result/time. Общие кадры разных ветвей должны совпадать целиком, включая подпись и результат. Источник изменился или общего кадра нет — возврат к обзору.

У блок-схем маркер проходит по ребру выбранного решения. В UML показан порядок вызовов/ответов и alt; вертикаль не является временем. На временной линии только исходные числовые отметки: равные интервалы движутся с равной скоростью; остановки на событиях считаются отдельно. У таблиц, иерархий, сравнений и исходных описательных цепочек — ручной фокус без притворного исполнения и роста значений от нуля.

При уменьшенном движении автоматический показ отключён, все состояния доступны вручную. В режиме двух окон только владеющая сеансом панель публикует состояние; аудитория показывает тот же сценарий, шаг, прогресс и раскрытую схему. Заметки не передаются этим каналом.

## Дизайн

Raleway; белая поверхность слайда, нейтральная структура, один красный фокус. Тёмная тема применяется к оболочке и раскрытому диалогу. Ромб условия, формы начала/конца, направления стрелок и call/return сохраняют смысл. Подписи видимы без hover, выбор ветви не определяется только цветом. Развёрнутый просмотр нужен также для небольшой панели преподавателя. Узкое окно получает читаемую структурную форму со всеми связями и исходами.

## PDF

Основные 553 печатных слайда сохраняют штатную верстку; задания и тесты, как и ранее, исключены движком из PDF. После них добавляется статическое приложение с 25 подробными схемами: все альтернативы, условия и результаты. Страницы приложения A4 portrait с обычным переносом содержимого, без контроллеров и автоматического движения. Для выбранной лекции/семестра включаются только её схемы.

## Проверка

`npm run typecheck`, `npm run lint`, `npm test`, `npm run build`, `npm run check:privacy`. Тесты проверяют привязки, реальные временные шкалы, обход всех сценариев, конечность, границы шагов, отмену движения при выборе ветви и точное продолжение паузы. Браузерная проверка дополняет их: полный обход визуализаций, два окна, уменьшенное движение, темы, небольшое окно и PDF. Числовые примеры, права, тесты и откат здесь являются учебной моделью; команды ОС, криптография и изменения ВМ не исполняются.
