## Экран 10. Id, RecordId и ActivityId: разные роли

ID: `s07-04-observing-operating-system-s010` · роль: `theory` · оценка: 42 с.

### Подготовка

Если планируется чтение журнала, заранее проверить Windows, доступ к Application и схему провайдера. Синтетическая выборка LabApp не является результатом команды; requestId/result извлекаются по схеме EventData.

### Речь, действия и переход

Показ: различим три столбца таблицы. Id обозначает тип события провайдера, RecordId — конкретную запись журнала, ActivityId — GUID активности, который может отсутствовать. Они не взаимозаменяемы. Команда Get-WinEvent читает Application и выбирает четыре события; она не создаёт события LabApp и не извлекает requestId автоматически. Поле requestId в учебном случае задаёт приложение по собственной схеме. По умолчанию новые события выводятся первыми: для хронологии порядок нужно учитывать.

### Вопросы группе

Может ли одинаковый Id доказать одну заявку?

### Ответ и разбор

Нет. Это один тип события, который могут породить разные операции. Для корреляции проверяют схему источника, requestId или используемый GUID активности, экземпляр и время. RecordId адресует запись, а не сквозную заявку.

## Экран 16. Четыре записи: разделяем A17 и A18

ID: `s07-04-observing-operating-system-s016` · роль: `example` · оценка: 50 с.

### Подготовка

—

### Речь, действия и переход

Перед нами синтетическая выборка LabApp, уже расположенная по времени. Два начала имеют Id 1001, но requestId A17 и A18 различны. Сопоставляем A17 с завершением в 10:14:03: три секунды и failed. A18 заканчивается в 10:14:04, тоже через три секунды, но accepted. requestId и result здесь взяты из EventData учебного провайдера. У конкретного провайдера схему пользовательских полей проверяют в XML через ToXml(), а не выбирают произвольную позицию Properties как универсальный requestId.

### Ответ и разбор

A17: начало 10:14:00, конец failed в 10:14:03 — три секунды. A18 отдельна: 10:14:01–10:14:04, accepted. Id классифицирует тип, requestId различает операции по схеме LabApp.
