# ОКФКС: утверждённые тексты и сценарии от 22.10.2026

Исходный комплект перенесён из проекта BrainM «Аудит готовых лекций / Тексты ОКФКС для преподавателя». Он содержит семь связных текстов лекций, семь сценариев панели, карты всех 777 слайдов и пакеты заметок. Содержание относится к версии `2.1.0-design-review-20261021`; порядок слайдов, задания и записи в тетрадь сохранены.

`Источники/course.json` и `Источники/assessment.json` фиксируют точную редакцию курса. `Источники/notes.baseline.json` фиксирует предыдущие авторские заметки для обновления автоматически загруженных полей. Это опубликованные авторские материалы; персональных записей из браузера здесь нет.

Воспроизведение из корня репозитория:

```sh
npm ci
npm run migrate:content
npm run validate:content
```

`authoring/publish-teacher-text.mjs` накладывает утверждённый пакет после исторических правок курса и удаления служебных слайдов `s111`. Перед заменой он проверяет точное совпадение курса и банка заданий, версию, полный набор ID и все шесть полей. Поля заметок не дополняются текстом маршрута занятия; маршрут публикуется отдельно.

Генерация сохраняет отпечатки предыдущих авторских полей, включая время как `String(estimatedSeconds)`, и исторические отпечатки совместимых редакций. Это позволяет загрузчику обновить прежний авторский текст, сохранив ручные изменения преподавателя.

Исходные MD, сценарии MD, карты, пакеты и отчёт остаются только в репозитории. Генератор накладывает очищенные заметки на `public/teaching/notes.json` для панели, но не создаёт публичных MD, частичных пакетов, карт или ZIP. Скачивание на сайте ограничено PDF слайдов.

Исходные метки `sourceKind: local` и `runtimeChecked: false` в MD описывают состояние на момент создания комплекта. Проверку интеграции с сайтом следует фиксировать отдельно от этих исходных документов.
