# Источники проекта

- `PROMPT.md` — предоставленный пользователем мастер-промпт и структурированный текст РПД;
- `SOURCES.md` — человекочитаемый реестр и ограничения публикации;
- `src/data/sourceRegistry.ts` — машиночитаемый реестр, используемый интерфейсом;
- `public/brand` — предоставленные фирменные ресурсы и согласованный маскот;
- `public/qr/okfks-materials.png` — программно созданный и декодированный QR-код.

Техническая учебная платформа зафиксирована как Windows 11 24H2 в изолированной среде. Примеры PowerShell в презентации читают состояние; изменение настроек допускается только в разрешённом учебном стенде с планом возврата.

Ссылка на Яндекс Диск сохранена без просмотра содержимого по прямому указанию пользователя. Названия файлов и наличие материалов не заявляются.
