3. «Найди ошибку»: единицы времени, уведомления вместо отказов, округление у порога. Подсказки, повторные попытки, объяснение правильного выбора и прогресс по трём случаям. Это учебное упражнение, не экзамен и не общий рейтинг.

Кнопка «Преподавателю» открывает вопрос группе, порядок демонстрации, ожидаемый ответ и ориентировочное время для каждого этапа. В `public/teaching/notes.json` обновлены четыре заметки: s027, s038, s060, s071 второй темы. Авторский генератор воспроизводит эти дополнения; частные файлы пользователя не перезаписываются. Личные браузерные правки имеют прежний приоритет над опубликованным комплектом.

## Статичный сайт и переносимость

Оформление использует общий stylesheet фиксированного `@olgakraven/lecture-engine`: классы панели, кнопок, прогресса, рамки слайда, шапки, логотипа и орнамента. Шрифт Raleway, красные акценты, белый учебный слайд и синие пояснения соответствуют проекту. Отдельный тёмный баннер и зелёная палитра пилота заменены оформлением курса. В автономное демо встроены исходные логотип, орнамент и локальный файл шрифта; перерисовок бренда нет.

Вычисления и обратная связь работают в JavaScript браузера. Сервер, внешние игровые сервисы и сетевые ресурсы мастерской не нужны. Проектная версия входит в стандартную сборку Vite. Автономное демо со встроенными CSS и JavaScript собирается командой `npm run build:pilot`; файл можно перенести для оценки пилота. Ссылка «К лекции» в автономном демо ведёт на сайт курса и требует сеть.

Математика и валидация состояния вынесены в `src/lab/reliability.ts`, интерфейс и стили — в отдельные файлы. Это основа для дальнейшего применения подхода; универсальный редактор игр для разных дисциплин ещё не реализован. Для другого продукта меняются данные, сценарии, бренд и интеграция с его страницами.

Прогресс хранится в отдельном ключе `okfks:reliability-workshop:pilot-1`. Сброс затрагивает только мастерскую. Он не меняет заметки, позицию чтения и результаты заданий лекции. При недоступном хранилище интерфейс продолжает работать с предупреждением; записи не отправляются преподавателю и не синхронизируются между устройствами.

Показ на проекторе — одна управляемая страница. Отдельное окно audience штатного движка не синхронизирует мастерскую. Её печатный вариант выводит исходный пример, текущие настройки симулятора и все три разобранных случая; это дополнительный лист, а не новые слайды в PDF курса.

## Проверки

- 14 тестов: прежние 11 и три проверки расчёта завершённых циклов, изменения простоев/сравнения до округления и повреждённого сохранённого состояния.
- validate:content, TypeScript, production build, lint, check:privacy и автономная сборка.
- Chrome: исходные 40 ч / 2 ч / 95,24 %; быстрый сценарий 40 ч / 1 ч / 97,56 %; неверная и правильная попытки, все три решения, счётчик 3/3, запись прогресса.
- Ширина 390 px: отсутствие расширения body и переполнений элементов; подписи ленты увеличены, значения также доступны на кнопках циклов; элементы range имеют явные доступные имена.
- Автономное демо не запрашивает CSS, шрифты, JavaScript и изображения по сети; печатное представление содержит все три раздела.
- PDF второй темы: 112 страниц, 5 QR декодированы, штатная проверка DOM/SVG без переполнений. Остальные PDF не пересобирались локально для этого пилота: их данные не менялись; GitHub CI проверяет весь комплект.

Физический проектор, Safari и проведение занятия с группой не проверены. Пилот предназначен для оценки подачи; распространение на другие темы и продукты выполняется после обратной связи пользователя.
