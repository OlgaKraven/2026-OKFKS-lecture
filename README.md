# МДК.04.02 «Обеспечение качества функционирования компьютерных систем»

Версия содержания **2.0.0-template-aba617d**. Семь переработанных лекционных тем, по 112 слайдов; всего 784 слайда, 56 учебных вопросов, 224 задания и 119 визуализаций. Семестры 7 и 8. Часы сохранены отдельно: лекции — 32, лабораторные — 44, самостоятельная работа — 28.

![Каталог курса](public/og.png)

Проигрыватель, каталог, самопроверка, печать и два окна предоставлены общим пакетом из [2026-lecture-shablone](https://github.com/OlgaKraven/2026-lecture-shablone/tree/aba617d886eb33194e5c1283049f23a9d4452464). Используется локально собранный `@olgakraven/lecture-engine@0.1.1-okfks.2`: шаблон 0.1.0 с исправлением печатной типографики и отображения отсутствующего учебного года. Исходный patch и происхождение находятся в `vendor/`. Пакет не опубликован в npm и не обновляется во время занятия.

## Запуск и проверки

Node.js 22.18+; проверено локально на Node.js 24.11.1, npm 11.13.0.

```sh
npm ci
npm run dev
npm run lint
npm run typecheck
npm test
npm run build
npm run check:privacy
```

Production-просмотр: `npm run preview`. Базовый путь сохранён: `/2026-OKFKS-lecture/`. Старые ссылки `?topic=...&slide=25` переводятся в стабильные ID; старая страница `print/` открывает новое ученическое представление. Существующий профиль `okfks.teacherProfile` переносится в новую настройку, если она ещё не заполнена. Старые результаты тестов не переносятся: задания и версия содержания изменились.

## Содержание и контекст

`public/course.json` — единые ученические данные для сайта и PDF; `public/assessment.json` — отдельные ключи автономной учебной проверки. В каждом блоке идут single, multiple, short и matching. У соответствий четыре пары, множественный выбор оценивается только за полный набор.

В `authoring/context.mjs` находятся 56 предметных объяснений и разобранных ситуаций: условия, рассуждение, результат, заблуждение, вопрос с ответом. Сохранённые исходники находятся в `authoring/legacy/`; они не подключаются к сайту. Общие поручения заменены конкретными разборами. Карта каждого старого слайда — `authoring/migration-map.json`; программа, словарь и связи объяснений с тестами — остальные файлы `authoring/`.

После правок авторских данных:

```sh
npm run migrate:content
npm run build
```

Генератор не перезаписывает существующий `private/teacher-pack.json`: новый вариант сохраняет как `teacher-pack.generated.json`. Сравните его с отредактированным комплектом перед заменой. `teacher.md` — производная текущего сгенерированного набора, а не самостоятельный источник. Прямые правки `course.json` будут заменены следующей миграцией: основные изменения вносите в авторские данные.

## Сценарий и два окна

Откройте тему → «Начать занятие в двух окнах» → «Загрузить заметки» → выберите отдельно переданный `teacher-pack.json`. Комплект содержит заметки ко всем 784 стабильным ID, совпадающие `courseId` и `contentVersion`. Изменения и экспорт выполняются штатной панелью; перед заменой своих заметок сохраните экспорт.

Приватный комплект не хранится в Git, `public/` или `dist/`. В окно аудитории передаётся состояние показа; полный сценарий остаётся у преподавателя. Разбор текущего теста раскрывается явным действием. Учебные ключи в `assessment.json` доступны технически — это автономная самопроверка, а не защищённый экзамен.

## PDF

Из каталога доступны PDF темы, семестра и всего курса. Пакетный экспорт использует то же печатное представление, ожидает шрифт и изображения, декодирует QR и проверяет количество страниц и переполнение.

```sh
npm run build
npm run export:pdf
npm run export:pdf -- --topic s07-02-reliability-metrics
npm run export:pdf -- --output outputs/pdf/student
```

По умолчанию используется установленный Chrome. Для Chromium установите его командой `npx playwright install chromium` и задайте `BROWSER_CHANNEL=chromium` в окружении. Экспортирует только ученический PDF, один слайд на страницу. Сценарий выдаётся отдельно, не через переключение публичного PDF в «teacher».

## Источники и границы готовности

Сохранены исходные названия, библиография, фирменные ресурсы и [папка материалов](https://disk.yandex.ru/d/Vz62H71Jub1GLA). Учебный год и ФИО не выдуманы; год пока пуст, преподаватель задаётся в настройках. Основа карты — текст РПД внутри исторического `PROMPT.md`, а не полный утверждённый документ. Исторические команды из него не являются текущими указаниями.

У последней темы на полный последовательный маршрут требуется больше 90 минут; это отражено в `reports/lecture-registry.json` и `reports/QA.md`. Расчёт времени — ориентир, не результаты занятия. Принудительного сокращения темы или изменения часов нет.

Ветка с изменениями сама по себе не обновляет [публичный сайт](https://olgakraven.github.io/2026-OKFKS-lecture/). Публикация сохраняет существующий GitHub Actions workflow и происходит после попадания изменений в `main`. Локальные проверки и фактические ограничения описаны в `reports/QA.md`.
